Chat With PDF

Project 03 / 09 Retrieval-augmented generation ← All projects

Ask questions across several PDFs and get answers grounded in the retrieved passages.

Live demo ↗Source ↗

Overview

A document question-answering application that lets users chat with multiple PDFs. It combines document extraction, BAAI embeddings, and a Llama model to answer questions using relevant document content.

How it works

  1. 01Extract content from uploaded PDF documents.
  2. 02Embed and retrieve relevant passages using vector search.
  3. 03Generate answers grounded in the retrieved document context.

Stack

  • LlamaIndex
  • FAISS
  • ChromaDB
  • LangChain
  • pypdf
  • Hugging Face
  • Streamlit
  • Python
